# Marketing Skills for Claude Code

53 marketing skills that Claude Code loads automatically when you work in this repo.

Ask for what you need in plain language, like "write homepage copy" or "audit this page's SEO," and Claude picks the right skill.

## What's inside

Copywriting, copy editing, CRO, SEO audits, AI search, pricing, offers, emails, cold email, ads, launch planning, analytics, and more. Each skill lives in its own folder under `.claude/skills/`.

## Use them

1. Clone this repo.
2. Open it in Claude Code.
3. Ask for a task, or call a skill by name, like `/copywriting`.
