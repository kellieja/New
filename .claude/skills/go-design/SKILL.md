# Design and websites

Pick one skill from the table, load it with the Skill tool, and do the work. Say in one line which skill you used. If the request spans two rows, run them in order.

| If they want to... | Use |
|---|---|
| Build a website, page, or component | `anthropic-skills:frontend-design` |
| Get a critique of a design or page | `design:design-critique` |
| Check accessibility (contrast, keyboard, screen readers) | `design:accessibility-review` |
| Improve a page so more visitors convert | `cro` |
| Plan site pages, navigation, or URL structure | `site-architecture` |
| Create or edit marketing images and graphics | `image` |
| Brand colors, type, logo rules, style guide | `brand` |
| 3D scenes or effects | see `/go-3d` |

If a named account or plugin skill isn't available in this session, say so and use the closest repo skill instead.
