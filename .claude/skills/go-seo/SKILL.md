# SEO

Pick one skill from the table, load it with the Skill tool, and do the work. Say in one line which skill you used. If the request spans two rows, run them in order.

| If they want to... | Use |
|---|---|
| Find out why a site isn't ranking, or audit SEO | `seo-audit` |
| Show up in ChatGPT, Google AI answers, Perplexity | `ai-seo` |
| Add structured data or rich results | `schema` |
| Plan pages, navigation, URLs, internal links | `site-architecture` |
| Earn backlinks | `link-building` |
| Get listed in directories | `directory-submissions` |
| "Us vs them" or "alternatives" pages | `competitors` |
| Build many pages from a template | `programmatic-seo` |
| Plan what content to publish | `content-strategy` |
| App Store or Google Play listing | `aso` |

Not sure where to begin: run `seo-audit` first. It points to the next skill.
