# Writing

Pick one skill from the table, load it with the Skill tool, and do the work. Say in one line which skill you used. If the request spans two rows, run them in order.

| If they want to... | Use |
|---|---|
| Write a new web page, landing page, or section | `copywriting` |
| Tighten, edit, or review existing copy | `copy-editing` |
| Email sequences, newsletters, lifecycle emails | `emails` |
| Cold outreach emails or LinkedIn messages | `cold-email` |
| Text messages (SMS) | `sms` |
| Popup or banner copy | `popups` |
| Ad headlines and ad text | `ad-creative` |
| Match or define a brand's voice | `brand` |
| Social posts | `social` |

Unsure between `copywriting` and `copy-editing`: if there's existing copy to fix, edit it; if not, write it.
