# Sales

Pick one skill from the table, load it with the Skill tool, and do the work. Say in one line which skill you used. If the request spans two rows, run them in order.

| If they want to... | Use |
|---|---|
| Find and research prospects | `prospecting` |
| Write cold emails or LinkedIn outreach | `cold-email` |
| Pitch decks, one-pagers, objection handling, battle cards | `sales-enablement` |
| Lead routing, CRM, pipeline, handoff from marketing | `revops` |
| Learn what customers want before pitching | `customer-research` |

Draft all outreach for approval. Never send on the user's behalf without explicit approval of the list and the copy.
