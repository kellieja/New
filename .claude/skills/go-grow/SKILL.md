# Strategy

Pick one skill from the table, load it with the Skill tool, and do the work. Say in one line which skill you used. If the request spans two rows, run them in order.

| If they want to... | Use |
|---|---|
| A full marketing plan | `marketing-plan` |
| Positioning, messaging, who it's for | `product-marketing` |
| Make an offer more compelling | `offers` |
| Set or change prices | `pricing` |
| Launch something | `launch` |
| A lead magnet (guide, checklist, quiz) | `lead-magnets` |
| A free tool or calculator for leads | `free-tools` |
| Referral or word-of-mouth program | `referrals` |
| Partner with another business | `co-marketing` |
| Press coverage | `public-relations` |
| Webinars, workshops, events | `events` |
| Plan content topics | `content-strategy` |
| Understand customers (interviews, surveys) | `customer-research` |
| Profile competitors | `competitor-profiling` |
| See how a competitor grew and copy what works | `reverse-engineer-marketing` |
| Fresh marketing ideas | `marketing-ideas` |
| Why people buy (persuasion, psychology) | `marketing-psychology` |
| Pressure-test a big decision from several angles | `marketing-council` |
| Set up a recurring weekly marketing routine | `marketing-loops` |

New client, nothing in place: `product-marketing` first, then `marketing-plan`.
